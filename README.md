# Introduction
My laptop is an ASUS Vivobook 15 that runs Arch Linux and Hyprland as the Window Manager and the wayland compositor.  
  
In this repository, you can find my exact configuration files.  
  
These are not completely made by me, I've used custom presets provided by others and slightly modified them to fit my needs.  
  
The **allpkgs.txt** contains all of my Arch Linux packages, including dependencies or ones which were not explicitly installed.  
  
The **pkglist.txt** contains all of my explicitly installed Arch Linux packages. These are the ones I installed with the usual 'sudo pacman -S' command.
